# Gmail Registration Demo

A simple web application that demonstrates **Gmail-style registration form functionality** built using C# (.NET) and front-end technologies.

This project shows form validation, UI design, and basic HTML/CSS integration for an email registration feature — ideal for learning, demoing UI/UX behavior, or expanding into full apps.

---

##  Features

✔️ Registration form with email and password fields  
✔️ Client-side and server-side validation  
✔️ Clean and responsive UI  
✔️ .NET back-end handling

---

##  Built With

This project uses:

- **ASP.NET MVC / C#** – server logic  
- **HTML / CSS** – front-end layout and styling
